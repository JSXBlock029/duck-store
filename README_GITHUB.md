# 🦆 Duck Store - Premium Duck Picture Sales Platform

A modern web application for selling high-quality duck pictures with secure credit card payments powered by Stripe.

## 🌟 Features

- **🖼️ Beautiful Gallery** - Browse and search duck pictures by category
- **🛒 Shopping Cart** - Add multiple pictures to cart
- **💳 Secure Payments** - Stripe-powered credit card processing
- **📱 Responsive Design** - Works perfectly on all devices
- **👑 Admin Panel** - Manage pictures, orders, and view analytics
- **🔍 Search & Filter** - Find the perfect duck picture

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Database**: SQLite (can upgrade to PostgreSQL)
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Payments**: Stripe API
- **Hosting**: Vercel (Serverless)

## 🚀 Quick Start

### Local Development
```bash
# Clone repository
git clone https://github.com/lowriskbtc/duck-store.git
cd duck-store

# Install dependencies
pip install -r requirements.txt

# Run locally
python duck_store.py
```

### Deploy to Vercel
1. **Fork/Clone** this repository
2. **Connect** to Vercel
3. **Deploy** with one click
4. **Configure** environment variables

## 💳 Payment Setup

1. Create [Stripe Account](https://stripe.com)
2. Get API keys from dashboard
3. Add to Vercel environment variables:
   ```
   STRIPE_SECRET_KEY=sk_test_...
   STRIPE_PUBLISHABLE_KEY=pk_test_...
   ```

## 🎨 Customization

- **Colors**: Edit CSS variables in `templates/base.html`
- **Pictures**: Upload your own duck pictures via admin panel
- **Categories**: Add new picture categories
- **Pricing**: Set your own prices for each picture
